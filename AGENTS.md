# ParaPo project context

- ParaPo is a small school prototype/demo. It is not planned for production or public launch.
- Keep collaboration casual, direct, and practical. Avoid unnecessary formality, enterprise process, or production-readiness work.
- Anyone on the project can handle any task. Do not require a project lead, data lead, evaluation lead, role assignments, or formal sign-offs unless the course specifically requires them.
- Prefer the smallest useful implementation and lightweight checks that fit a class project. Follow course requirements when they actually apply.
- Keep claims honest, but do not add approval paperwork or compliance gates for hypothetical deployment. Use reasonable care with any real people or footage in samples.
