To reproduce the v10 training run after the v10 local data folder has been prepared, run from the repository root in PowerShell:

```powershell
$mlPy = Join-Path $PWD 'datasets/m3-samples/.venv-v6/Scripts/python.exe'
@'
from pathlib import Path
from ultralytics import YOLO
root = Path.cwd()
YOLO(str(root / 'datasets/m3-samples/runs/yolov8n-v5-20ep/weights/best.pt')).train(
    data=str(root / 'datasets/m3-samples/yolo-v10/data.yaml'),
    epochs=20, patience=5, batch=2, imgsz=320, device=0, workers=0,
    seed=42, deterministic=True, pretrained=True, optimizer='auto',
    project=str(root / 'datasets/m3-samples/runs'),
    name='yolov8n-v10-replay', exist_ok=False,
    cls_remap=True, amp=True, verbose=False, plots=False,
)
'@ | & $mlPy -
```

This trains on the frozen training split and uses validation for early stopping. It does not run inference on the test split.
