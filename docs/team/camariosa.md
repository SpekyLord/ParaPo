# Camariosa — planner, maps and usability

## What you are helping finish

Check that someone can plan and understand a manual journey. Your photos have already helped the project; this is a separate new contribution.

## Before starting

Get Austria's current normal APK and build ID and an Android 14/API 34+ phone. If you cannot install it, pair with someone using the Tecno as observer/recorder, or review a current recording and report specific visible usability issues. Label your work **device testing**, **observation**, or **recording review**; mark unseen cases NOT RUN.

## Steps

1. On Home, enter or choose **Jaro Plaza** for **Starting point** and **WVSU** for **Destination**, then tap **Find my route**. Check that Route 3 and Route 10 appear with the correct direction.
2. For each card try **Show path on map** and **More details**. Check direction, boarding and getting-off information, ordered stops and returning to results. Use **See stops without a map** if offered.
3. Return Home, reverse the places, and repeat. Check the displayed direction and stops rather than assuming the same path backwards.
4. Set both places to the same location: the app should say no ride is needed. Try an unsupported place: search should show no match, or direct entry should say coverage cannot be confirmed.
5. With permission from the device owner, turn off internet and retry a manual journey and details. Record whether route cards, stops and schematic remain usable. Cached map tiles may still show; a complete offline street map is not promised. Restore the connection afterwards.
6. Check large system text, clipped controls and confusing wording. Record precise steps and screenshots where possible. A truthful no-issue result is fine.
