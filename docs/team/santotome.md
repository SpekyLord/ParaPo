# Santotome — independent photo and sign review

## What you are helping finish

Independently check a small set of the existing jeepney photos and labels. Thanks for the photos already contributed. Existing annotations have already been reviewed; your separate review can catch disagreements or uncertainty.

## Before starting

Ask Austria for the prepared 12-photo batch `parapo-review-v11-2026-11-15`, with image IDs and the separately supplied existing labels and sign boxes. Individual contributor names are not recorded. A phone is enough to inspect shared images; new photo collection is optional.

## Steps

1. Inspect each original photo and write the exact text you can actually see, preserving uncertainty. Do not copy a supposed answer from OCR output.
2. Mark the text readable, partly readable or unreadable. Compare your observation with the existing label and note disagreements.
3. Check whether the existing box includes the intended sign. Note whether the sign's vehicle is clear or uncertain; do not infer direction from a route number or the vehicle's appearance.
4. Record the source/contributor if known; otherwise write unknown. Suggest corrections separately, including uncertain cases. Leave original photos and frozen manifests unchanged.
5. Summarize recurring problems and any missing examples that would help. Collecting new images is optional; do not add raw photos to Git.

## Checklist

- [ ] Starter batch reviewed independently.
- [ ] Disagreements and uncertain boxes/owners recorded separately.
- [ ] Recurring problems and useful missing examples summarized.

## Send back and completion

Send the review table and short summary to Austria in the agreed group chat as plain text, screenshots or a document. Austria can integrate proposed corrections separately and record your credit. Complete means every supplied image has an actual observation or a stated blocker; you do not need to find a fixed number of errors.

## Presentation

Explain why labels and sample quality matter. Be ready to answer:

1. How did you decide what text was visible?
2. Why should uncertain text or vehicle ownership stay uncertain?
3. What can a misplaced box do to a sign-reading test?
4. What recurring issue or absence of issues did you observe?

## If blocked

Ask Austria for accessible permitted images, labels or box views. Mark missing source information unknown; never guess it.
